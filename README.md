## 📌 Описание проекта

Проект направлен на разработку онлайн-платформы (сайта) для преподавателей с использованием технологий искусственного интеллекта. Основная цель — создание удобного инструмента для разработки, проведения и анализа тестирования обучающихся.

В рамках проекта с помощью ИИ был создан сайт, позволяющий автоматически генерировать тестовые задания, проверять ответы и анализировать результаты. Платформа упрощает работу преподавателя, снижает затраты времени на подготовку материалов и повышает объективность оценки знаний.

Система может использоваться в рамках темы «Изучение порядка сборки ПК и подключения оборудования», а также адаптироваться для других учебных дисциплин.

## 🎯 Цель проекта

Создание современной образовательной платформы с использованием искусственного интеллекта для автоматизации тестирования и повышения эффективности обучения.

- Веб-разработка
